一条商品如何被写入

接收文档
校验标题、描述与类目，生成 384 维语义向量
→
WAL + 内存增量
顺序写日志并进入内存，即刻可被检索
→
后台落盘
单线程按序写入 H2 与三套索引，批量提交
→
对外可见
检索结果合并内存增量，删除项不再返回

当前为 delta 高速模式：崩溃时最多丢失最后一个刷盘间隔（约 200ms）的记录，重启后由 WAL 自动恢复。若业务要求每条都强持久化，可在配置中将 write.mode 改为 sync，代价是写入延迟上升。

录入商品文档

入库走 WAL + 内存增量，返回端到端耗时（对应 NFR-06）；索引更新由后台完成，无需手动重建。
