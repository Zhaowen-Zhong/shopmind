系统健康状态

检索服务
0
当前可被检索的商品文档总数。该数字持续增长属正常；若骤然归零，说明数据加载异常，需查看启动日志。
写入链路
delta
当前写入模式。delta 为高速模式：先写日志与内存，后台异步落盘；需要强持久化时可切换为 sync。
内存增量（Delta）
0 条
已可检索、但尚未由后台落盘的文档数。它会周期性归零；若长期只增不减，说明后台落盘线程可能阻塞。
待落盘 WAL
0 字节
等待落盘的日志体积。程序崩溃时，最多丢失最后一个刷盘间隔（约 200ms）的记录，重启后自动恢复。

架构与关键设计

自研语义向量检索

把商品与查询映射为同一向量空间，理解“意思相近”而非只看字面重合。

HASHING TF-IDF · 384D

HNSW 分层近邻图

上层长距离跳跃、下层精确收敛，是当下主流向量数据库的核心索引，此处从零实现。

HNSW · M16 / EF200

混合检索与重排

语义向量与 BM25 关键词加权融合，兼顾“理解意图”与“精确型号匹配”。

VECTOR + BM25 · ALPHA

自研二进制协议

12 字节定长帧头、长连接、心跳与令牌桶限流，比 HTTP 更轻量、可控。

NETTY · TCP 9099

LSM 式高速写入

热路径只追加日志与内存增量，后台批量落盘，将写入延迟压到微秒级。

WAL + DELTA · APPLIER

纯 Java · 离线运行

不依赖云端模型与外部中间件，数据与服务皆在本地，解压即可启动。

NO CLOUD · EMBEDDED H2
